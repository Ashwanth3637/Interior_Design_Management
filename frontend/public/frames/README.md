# 50 Frame Photos Directory

Place your 50 frame photo files in this directory with the following naming structure:

- `frame_01.jpg` (or `.png` / `.webp`)
- `frame_02.jpg`
- `frame_03.jpg`
...
- `frame_50.jpg`

The `ScrollFrameCard` component will automatically preload and scrub through these 50 photos as the user scrolls down the landing page!
